ENGINEERING FIRST

Built for serious gamers

🛡️

Anti-Cheat Compliant

Pure top-level transparent DWM layer. No DLL injection, no memory read/write. Works safely alongside all major anti-cheat engines.

🖱️

Zero Input Lag

Native Win32 WS_EX_TRANSPARENT pass-through. Every click and keystroke goes straight to your game, no interruptions.

⚡

DirectX Accelerated

Vector reticle renderer using WPF DrawingContext. Sub-1% CPU and GPU overhead — completely invisible to your frame budget.

🎯

8 Reticle Shapes

Classic Cross, Center Dot, Cross + Dot, T-Shape, Circle, Circle + Dot, Chevron, and Box. Cycle through them instantly in-game.

🎨

Full Customization

Control size, thickness, gap, opacity, outline contrast, and screen offset via pixel-level sliders. Includes 8 preset colors + custom hex input.

📦

No Installation

Single self-contained .exe file. No .NET runtime required. Download and run — settings auto-save to a local JSON file.

GETTING STARTED

Up and running in 3 steps

1

Download the executable

Click the Download button above to get CrosshairOverlay.exe. No installer, no admin rights needed.

2

Run the app & configure

Double-click the file to launch. Use the Settings panel to pick your reticle shape, color, size, and offset. The crosshair appears instantly over your desktop.

3

Play in Borderless Windowed mode

Set your game to Borderless Windowed (or Windowed). The overlay will sit perfectly on top. Press F10 to toggle it in-game.
